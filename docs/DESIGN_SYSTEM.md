## Сетка
Контент 1104px по центру (поля 168 при 1440). Базовая колонка **264px, гап 16**:
4 колонки = 264×4+16×3 = 1104. Каталог: сайдбар 264 + 16 + сетка 824 (3×264+2×16).
Вертикальный ритм: секции через 80px, внутри секций 24–32. Всё кратно 4/8.

## Радиусы и тени
Поля/кнопки/чипы-табы 10 · бейджи 6 · чипы 8 · карточки 12–16 · контейнеры (поиск/фильтр/саммари) 20
Тень только у дропдаун-панели: 0 8px 24px rgba(0,0,0,.08) + бордер line.

## Поиск (hero) = фильтр (каталог) — один компонент
Hero: контейнер light radius 20 padding 40; табы «По размеру / По авто / Поиск по каталогу»;
4 поля fill + CTA; строка чипов («Популярно: 205/55 R16…» / машины / частые запросы).
Состояния (фреймы 1–4 в Figma): пустой; по авто (Марка/Модель/Год/Модификация);
по каталогу (один инпут с лупой, плейсхолдер «Например: Nokian Hakkapeliitta 10 или артикул…»);
заполненный — значения dark SemiBold, CTA «Показать 340 шин →» (N живое, tabular-nums).
Каталог: тот же набор вертикально в сайдбаре 264 + Производитель, цена от/до, чекбоксы
Шипы/RunFlat, CTA «Показать N шин», Сбросить. Параметры ↔ URL query params в обе стороны.

## Контентные данные
Преимущества (реальные офферы старого сайта): −15% шиномонтаж при покупке шин · −30%
хранение при покупке от 4 шин · −10% покраска дисков · Доставка в регионы РФ.
Доставка (со стр. товара): по СПб в пределах КАД 500 ₽, от 30 000 ₽ бесплатно, до ПЭК бесплатно.
Соцдоказательства (можно в блок): 2545 шин продано · 1356 клиентов · 48 поставщиков · 538 доставок.
Бренды: BFGoodrich, Bridgestone, Continental, Cooper, Dunlop, Gislaved, GoodYear, Hankook,
Kumho, Maxxis, Michelin, Nokian, Pirelli, TOYO, Yokohama.
Услуги: Шиномонтаж, Мотошиномонтаж, Ремонт дисков, Покраска дисков, Хранение колёс.
