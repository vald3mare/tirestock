## Что изменилось (по темам)

### 1. Каталог и синк SelectTyres
- Чистые фото без вотермарка (Avito-фид) → `image_clean_url`, эффективное фото = clean ∥ токенное.
- Живучесть синка: порог здоровья (усохший фид не сносит каталог), сид из снапшота `products` — каталог не пустеет при недоступном фиде.
- Товар **не пропадает** при обнулении остатка: синк обнуляет `stock`, а не удаляет строку (нужны для ссылок из заказов и SEO-URL).
- Сортировка каталога (`?sort=price_asc|price_desc|name`, наличие всегда сверху; ORDER BY из белого списка — без SQL-инъекций).
- Реальные опции фильтра (бренды/размеры) из данных: `GET /catalog/facets`, фолбэк на статику.
- Фильтр наличия `?stock=in|out` (нужен админке — найти распроданные).
- 🐞 **Фикс:** фильтр цены падал 500 (`WhereSQL` ссылался на `po.price` — алиас удалённой мультигород-таблицы). Теперь `price`.

### 2. Мультигород — заведён и ОТМЕНЁН (важно для ревью)
- Миграции `0004`/`0005` вводили `product_offers` + city-aware листинг, переключатель города, поддомены.
- Миграция `0009` **всё это откатывает**: цена/остаток снапшотятся обратно в `products`, не-СПб товары удаляются, `product_offers` дропается.
- Удалены: `web/lib/city.ts`, `lib/get-city.ts`, `CitySwitcher.tsx`, `app/api/city/route.ts`. Появился `lib/shop.ts` — одна константа магазина (СПб).
- Итог для ревьюера: смотреть на **конечное** состояние (СПб-only); мультигород-код в истории — тупиковая ветка по решению владельца.

### 3. Интеграция с tradesk (заказы и формы)
- Оформление заказа → своя БД (outbox) → воркер с ретраями доставляет в **боевой** tradesk. Заказ не теряется.
- Формы «обратный звонок» и «заявка услуги» тоже уходят в tradesk (через outbox).
- 🐞 **Фикс идемпотентности:** ключ выводился из телефона+состава → повторный заказ молча дедуплицировался и не уходил. Теперь ключ рождается с формой (скрытое поле).
- Контракт tradesk вскрыт по `/ajax/*.php` Битрикса (разбор в `docs/OLDSITE_AJAX.md`), адаптеры за интерфейсами.

### 4. Витрина (UI)
- Настоящая корзина (кука + серверное чтение, server actions, undo-снекбар удаления).
- Состояние «нет в наличии»: серый бейдж + кнопка **«Уточнить при наличии»** (заявка с товаром → tradesk) вместо мёртвой кнопки.
- Мобильное меню-бургер (Figma 99:764).
- Страница **«Пункты выдачи»** свёрстана по макету Figma (была текст-заглушка): центральный склад + сетка карточек, живая карта Яндекс.Карт (виджет).
- Живая карта Яндекс.Карт также на `/contacts` (вместо плейсхолдера).
- **Услуги урезаны** до реальных (хранение + шиномонтаж): удалены плитки/пункты меню/страницы «Ремонт колёс», «Покраска дисков», «Мотошиномонтаж» (роуты → 404).
- **Смена главного адреса**: Зотовский пр. 11 → Петровская коса (по всему сайту).

### 5. Контентная админка (новое, за сессией)
Новые разделы, все по единому паттерну (миграция + пакет + CRUD за сессией + фронт список/редактор):
- **Страницы** (`content_pages`) — тексты/SEO-мета, правила блокировки indexed/system.
- **Преимущества** (`benefits`) — строка офферов над каталогом, редактируемая.
- **SEO-мета** (`seo_meta`) — title/description статических роутов → `generateMetadata`.
- **Пункты выдачи** (`pickup_points`) — адрес/метро/часы и **свой бейдж-акция у каждого** пункта.
- **Товары**: read-модель из SelectTyres переоформлена (плашка read-only, тумблеры показа) + вкладки наличия «Все / В наличии / Нет в наличии» (распроданные теперь видны).

### 6. SEO (священная корова)
- Гейт индексации `SITE_INDEXABLE` (fail-safe, по умолчанию ЗАКРЫТО): `robots.txt Disallow` + `X-Robots-Tag: noindex` на тестовом домене; прод открывается явным флагом.
- `generateMetadata` тянет мету из админки (главная, каталог, пункты, контент-страницы).

### 7. Инфра
- Демо-стенд для заказчика через **Cloudflare quick-туннель** (`deploy/demo-cloudflare.sh`, overlay host-сети `docker-compose.hostnet-demo.yml`).
- 🐞 Кэш оптимизированных фото в контейнере (том, TTL, потолок) — Next не пережимает фото заново.
- OpenAPI как источник контракта → генерация TS-типов.

## На что обратить внимание при ревью
- **Боевой tradesk включён** (`TRADESK_BASE_URL` в `deploy/.env`) — заказы/формы с демо уходят в реальную учётку с пометкой `DELIVERY_TEST_MARK`.
- Смотреть **конечное** состояние по СПб, не мультигород-код в истории.
- Удалённые сервисные страницы (disk-repair/disk-painting/motomounting) → 404 намеренно.
- Данные пунктов выдачи и адрес Петровская коса — частично демо; реальный список/координаты за владельцем (см. `TODO.md` → вопросы к Виталию).
